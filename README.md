# 纸间阅读笔记

支持本机使用和服务器部署的网页笔记工具。前端为原生 HTML/CSS/JavaScript，服务端使用 Python 标准库和 SQLite，无需安装 Python 第三方依赖。

- 文件库：新建与打开文件夹、新建文档，以及文档重命名、移动、复制和删除。文件夹和文档支持拖动排序，文档可拖入文件夹，文件夹可嵌套；也可使用 Alt + 上下方向键排序。首次使用会提供可编辑的说明文档；升级不会覆盖现有笔记。
- 新文档：没有个人模板时，正文和分析为空，顶部信息使用截图指定的默认值；有模板时可选择模板或新建空白，默认模板会自动选中。
- 个人模板：顶部「模板」可将当前文档存为模板，文件库的文档菜单也可「存为模板」。标题、作者、来源、日期、刊头、栏目、正文、分析和文字格式均可复用；支持设为默认、重命名、用当前文档更新、删除。新建文档是独立副本，不影响原模板。模板随账号同步，备份导入导出也包含模板。
- 编辑器：字体选择统一修改当前文档内容的显示字体（工具栏、文件库和设置保留界面字体），无需选择文字，设置随文档保存；字号支持默认字号与 10–72，选中文字后可单独调整或恢复默认。另支持文本类型、文字色、高亮、彩色下划线和波浪线、列表，以及文前和文后栏目。
- 工具栏会跟随光标、选区显示当前文本类型、字号和加粗/斜体状态；选区格式不一致时显示混合状态。文件库与经文弹窗均支持点击外部关闭，拖动选取时从内部松开到外部不会误关闭。
- 快捷键：点击文字工具栏的“快捷键”，或按 Ctrl + Alt + / 打开可搜索的帮助侧栏，面板打开时仍可编辑。支持 Ctrl + S 保存并同步、Ctrl + Alt + O 打开文件库、Ctrl + Alt + N 新建文档、Ctrl + Alt + P 切换预览、Ctrl + Alt + B 查找经文。文本编辑区支持加粗、斜体、下划线、删除线、高亮、标题、字号和列表快捷键；完整按键见帮助面板。Mac 使用 Command 替代 Ctrl。
- 预览：讲义与表格版，可调整阅读字号、打印为 PDF、导出两倍分辨率 PNG。长文按最多 5000 CSS 像素分图导出。讲义版在文前栏目与正文、正文与文末总结之间使用红线分隔；表格版将文前、文后栏目接入同一张表格。
- 圣经：首次打开时读取 `data/Bible1.csv`，按卷章浏览；空格分隔关键词并同时匹配，支持包含和字符顺序模糊匹配。多选可跨章节与搜索结果，复制按原文顺序排列。关闭按钮、Esc 或点击外部关闭均清空多选。

## 本机启动

安装 Python 3.10 或更新版本（本机测试使用 3.13），在本目录执行：

```powershell
python server.py --host 127.0.0.1 --port 4173
```

打开 http://127.0.0.1:4173/index.html 。请使用 `server.py` 启动，普通静态文件服务器不提供登录与同步接口。

首次打开时必须创建管理员账号。管理员进入“账号与同步 → 管理子账号”，可以创建子账号、修改显示名称、重置密码、停用和删除子账号。管理员账号受到保护，不能通过子账号管理入口删除或停用。

未初始化时登录页显示管理员设置；完成初始化后恢复普通登录与注册。只有初始化账号是管理员，用户自行注册和后台创建的子账号均为普通用户。

用户自行注册必须填写有效注册码，默认注册码为 `108084`。管理员可在“管理子账号 → 注册设置”中查看、修改注册码（4–64 个字符），保存后立即生效，旧注册码随即失效。注册码保存在服务端数据库，重启或更新不会恢复默认值；普通用户不能读取或修改注册码。管理员直接创建子账号时不需要填写注册码。

完成初始化后，可以登录、注册或选择暂不登录。已有浏览器笔记保留在原来的本机文档库；登录后通过“账号与同步 → 导入本机文档”选择导入，不会自动上传其他本机账号的内容。

## 账号与同步

- 登录后，文档库按服务端账号独立存储；同一账号在不同设备上登录同一部署地址即可同步。后台约每 15 秒检查更新，编辑后自动上传，也可点击同步状态手动同步。
- 已打开的编辑器断网后仍可编辑，恢复连接后重试同步；尚未上传的内容保留在当前浏览器缓存中。这不是完整的离线 PWA，不保证断网时首次打开或重新加载应用。
- 两端同时修改时，会提示冲突；可以保留两个版本，或先下载本机备份再采用服务器版本。
- 未登录的笔记仅保存在当前浏览器；可通过账号设置导出 JSON 备份、合并导入备份。清除浏览器数据前请确认同步或备份已完成。
- 密码使用随机盐与 PBKDF2-SHA256（600,000 次迭代）保存。登录会话使用 HttpOnly、SameSite Cookie；服务端校验账号权限，子账号不能读取其他账号的文档或访问管理接口。密码重置和停用会撤销相关会话。

## 服务器部署

使用安装器后，程序位于 `/opt/paper-bound`。安装时可指定自己的数据文件夹，也可用 `bash install.sh --port 9188 --data-dir /你的专用文件夹`。账号、文档和个人模板保存在该文件夹下的 `notes.sqlite3`，更新备份在其 `backups/` 中；更新默认沿用原路径和端口。已安装后用 `--data-dir` 换目录会先备份，再复制数据，原目录仍保留，目标已有数据库则停止。上传 ZIP 的解压目录只作为安装来源；手动运行 `sh start.sh` 时，数据默认位于项目内的 `storage/`，与安装器方式不同。

**不需要容器。最简单只需：上传解压 → 运行安装命令 → 输入端口和数据文件夹 → 浏览器打开。**

```sh
cd /你的解压目录
sudo bash install.sh
```

1Panel 的 root 终端直接执行 `bash install.sh`，无需 sudo。也可以 `sudo bash install.sh --port 9188 --data-dir /data/paper-bound` 一次指定空闲端口和专用数据文件夹，路径包含空格时加引号。安装脚本由 root 执行，网页服务以受限的 `paper-bound` 系统账号运行；安装器会预先检查该账号对所选目录及上级目录的访问权限，不会擅自放宽 NAS 其他目录权限。脚本也会检查端口、设置开机自启，并在更新前备份数据库。安装后访问脚本显示的 `http://内网IP:你选的端口`，FRP 目标端口填写相同值。

需要采用 systemd 的 Linux。运行环境是宿主机 Python 3.10+；没有容器、npm build 或 pip 依赖。1Panel、内网 HTTP + IP、FRP 和手动启动的完整说明见 [非容器部署说明](deploy/README.md)。账号和同步需要服务进程，仅上传 HTML 到静态网站目录无法提供这部分功能。内网 HTTP 与公网 HTTPS 同时使用时，原生配置保持 `NOTES_SECURE_COOKIES=0`，让两个入口都能登录。

`/api/version` 可以核对实际版本、运行文件是否完整，以及更新后是否忘记重启。JS/CSS 地址带发行版号，应用页面和脚本要求缓存重新验证。

**后续更新：** 先确认文档已同步，把新版 ZIP 解压到新目录，在新目录运行 `bash install.sh`；端口、数据目录提示均回车保留原值。安装器会先备份数据库，再更新程序，保留账号和文档。不要删除你设置的数据文件夹；[完整更新说明](deploy/README.md#6-更新与迁移)包含迁移和故障处理步骤。

### Docker（可选）

已提供 Dockerfile、Compose 和 Caddy 配置。服务器需要 Docker Compose、可解析到服务器的域名，以及开放的 80/443 端口。

1. 将项目文件上传服务器，保留 `fonts/`、`vendor/` 和 `data/`。
2. 复制 `.env.example` 为 `.env`，将 `NOTES_DOMAIN` 改为实际域名，不要包含协议前缀。
3. 执行 `docker compose up -d --build`。
4. 访问 `https://你的域名`，立即创建首个管理员账号，再创建子账号。

Caddy 自动申请 HTTPS 证书。Compose 已启用 Secure Cookie，必须通过 HTTPS 访问；本机 HTTP 预览不要设置 `NOTES_SECURE_COOKIES=1`。

服务端数据保存在 `notes-data` 持久卷的 `/data/notes.sqlite3`，重建容器会保留数据。不要执行 `docker compose down -v`，该命令会删除持久卷。备份时可以先停止 app 服务，再完整备份数据卷；也可使用 SQLite 的在线备份接口。恢复时将备份放回数据卷并保留容器用户 UID 10001 的读写权限，然后启动服务。浏览器导出的 JSON 是文档备份，不包含账号和密码。

不用 Docker 时，也可直接运行 `server.py --host 0.0.0.0 --port 8080`，使用进程管理工具保持运行，并在前面配置 HTTPS 反向代理。`NOTES_DATA_DIR` 指定持久数据目录，`NOTES_SECURE_COOKIES=1` 用于 HTTPS 部署。当前架构适合单实例部署，不应让多个应用实例同时共享同一 SQLite 文件。

本机没有 Docker，容器构建尚未实测。应用本身已在宿主机 Python 服务上测试；没有访问或操作用户实际的 1Panel / FRP 服务器。

## 验证

执行 `python -m unittest test_server test_install_data -q` 验证服务端初始化、账号权限、用户数据隔离、同步版本冲突、管理操作、静态文件访问范围，以及安装器的数据目录与迁移逻辑。测试使用临时数据库，不修改实际用户数据。

`output/playwright/` 保存开发阶段的浏览器验证脚本和截图。本次已验证管理员初始化、文件夹与文档拖放、同账号多浏览器同步、离线恢复、冲突保留双版本、账号隔离、字体作用范围和讲义/表格预览。

2026-10-27 修复：普通 HTTP + IP/域名访问时，浏览器不提供 `crypto.randomUUID()`，旧版会在文档库初始化时报错，连带使导入等操作失效。现在使用 `getRandomValues()` 生成文档 ID，并提供超时与数据克隆兼容方法。回归测试增加 HTTP 非安全上下文、旧 API 缺失、真实文件导入、菜单互斥、登录后保存与重载，避免只验证 localhost。

维护者发布前执行 `python tools/release.py 版本号` 更新资源版本和运行文件指纹，再运行测试并提交。用户下载完整发行版无需运行发布工具。
